# Cerrajero Reus

Sitio estático preparado para GitHub Pages.

1. Sube **el contenido de esta carpeta**, no la carpeta contenedora, a la raíz de la rama main.
2. En Settings → Pages, selecciona Deploy from a branch → main → /(root).
3. La URL prevista es https://cerrajeria-tarragona.github.io/cerrajero-reus/
4. Envía https://cerrajeria-tarragona.github.io/cerrajero-reus/sitemap.xml a Search Console.

Importante: confirmar nombre comercial, horario real, cobertura y reseñas verificadas antes de publicarlas. Las páginas no prometen disponibilidad 24 h sin verificar.
